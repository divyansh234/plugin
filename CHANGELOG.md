# Dropzone changelog

## 1.5.0
- Premium previews: custom video player (seek bar, volume, speed, previous/next, frame filmstrip you can click), audio player with a waveform that doubles as the seek bar, photo viewer with zoom, pan and neighbouring-photo strip
- Details card for every preview: codec, frame rate, color space, sample rate, bit depth, file size, modified date (richer when ffmpeg is installed)
- Expand button for a bigger preview; refreshed blue accent

## 1.4.0
- Search now looks inside subfolders (and, optionally, all your saved folders and My Files): choose "This folder", "+ Subfolders" or "Everywhere" next to the search box
- Results show where each file lives, and also match folder names (typing "beach sunset" finds sunset.jpg inside a "beach" folder)
- Background indexing keeps the panel smooth on big folder trees; results appear as the scan progresses

## 1.3.0
- Smart search: ignores capitals, punctuation and accents; tolerates typos, missing or swapped letters ("intrp" finds "Intro"); several words can be typed in any order; best matches are listed first

## 1.2.0
- Smooth previews: ProRes / HEVC / MXF and other formats play via a cached 480p copy (needs ffmpeg), plus a "Smooth preview" button for heavy files
- ffmpeg thumbnails for files the panel can't decode itself (PSD, TIFF, HEIC, ProRes...)
- Auto-refresh when files are added or removed in the open folder
- Keyboard control: arrows, Shift-select, Enter, Space, Ctrl/Cmd+A, search, Backspace, Home/End, Esc
- Enter inserts several clips back-to-back from the playhead
- Version badge and Settings panel (⚙)

## 1.1.0
- Faster panel, My Files (individual files), Grid / Large / List views

## 1.0.0
- Folder browser, drag to timeline, preview, multiple folders, modern UI
